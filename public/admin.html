🔑 Password Recovery

The server requires your current password to change it. If you've truly forgotten it, you must reset via MongoDB Atlas:

1. Open MongoDB Atlas → Browse Collections → settings
2. Delete the document
3. Set a new ADMIN_INITIAL_PASSWORD env var in Render
4. Redeploy
